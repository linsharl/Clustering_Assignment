# Clustering Assignment
## Overview
This project applies clustering algorithms to the Iris dataset using Python and Jupyter Notebook.
## Dataset
The Iris dataset contains four numerical flower measurements:
Sepal length
Sepal width
Petal length
Petal width
The species labels are not used when performing clustering.
# Algorithms
## KMeans Clustering: Groups flowers into clusters based on their measurements.
## Hierarchical Clustering: Groups similar flowers by repeatedly merging clusters.
# Data Preprocessing
The dataset is loaded using Scikit-learn, and the numerical features are standardized using StandardScaler.
# Visualization
Scatter plots are used to visualize the clusters produced by both algorithms.
